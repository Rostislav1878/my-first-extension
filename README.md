# Плагин: Insert Timestamp (Вставка текущего времени)

**Автор:** [Пасечник Ростислав Игоревич]
**Группа:** [М3119]

## Описание
Плагин для Visual Studio Code, который позволяет быстро вставлять текущую дату и время в любом месте текстового документа. Это удобно для ведения логов, заметок или комментариев в коде.

## Возможности (Features)
- Вставка текущей даты и времени в формате `YYYY-MM-DD HH:MM::SS`.
- Поддержка горячих клавиш для мгновенной вставки (Windows: `Ctrl + alt + t`, macOS: `cmd + alt + t`)
- Команда доступа через палитру команд (Command Palette)

## Архитектура
Плагин написан на TypeScript с использованием VS Code Extension API.
1. При активации расширения (в файле `extension.ts`) регистрируется команда `my-first-extension.insertTimestamp`.
2. Когда пользователь вызывает команду, плагин получает доступ к активному окну редактора (`vscode.window.activeTextEditor`).
3. С помощью встроенного объекта `Date()` генерируется текущее время, которое форматируется в читаемый вид.
4. Метод `editor.edit()` вставляет полученную строку в позицию курсора.
