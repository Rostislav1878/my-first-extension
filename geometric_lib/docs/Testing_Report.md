## План тестрования (Лабораторная работа №4)

### 1. Цели и задачи тестирования
**Цель:** Проверить корректность работы функций вычисления площади и периметра геометрических фигур.
**Задачи:**
- Проверить правильность математических вычислений.
- Проверить работу функций с нулевыми значениями.
- Проверить работу с дробными числами (для круга).

### 2. Описание тестируемого продукта
Библиотека `geometric_lib` содержит функции для вычисления площади и периметра трёч фигур: круга (`circle.py`), квадрата (`square.py`), прямоугольника (`rectangle.py`) и треугольника (`triangle.py`). Функции принимают числовые значения (радиус, сторону или стороны) и возвращают числовой результат.

### 3. Область тестрирования
Тестируются все функции из файлов `circle.py`, `square.py`, `rectangle.py` и `triangle.py` (функции `area` и `perimeter` для каждой фигуры).

### 4. Стратегия тестирования
Используются метод **ручного тестирования** и **автоматизированное Unit-тестирование** ( библиотека `unittest`).
Типы тестирования: функциональное тестироване (проверка соответствия результатов математическим формулам).
Для сравнения ожидаемых и фактических результатов используется оператор `assertEqual` и `assertAlmostEqual` (для чисел с плавающей точкой).

### 5. Критерии приемки
Тестирование считается успешным, если все написанные Unit-тесты проходят без ошибок (вывод `OK` в консоли), а результаты вычислений соответствуют математическим ожиданиям.

### 6. Ожидаемые результаты
Ожидается, что все функции возвращают корректные значения площади и периметра. В случае ошибок в коде (например, неверная формула) тесты должны выдать ошибку `FAIL` с указанием конкретного несоответствия.
